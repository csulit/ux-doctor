# Rule tensions: genuine trade-offs

> Hand-written file — NOT generated. Only cite rule IDs that exist in `rules.json`.

Conflicts between rules are resolved inside the rules themselves: a rule that yields to another says so in its **Scope** field (printed by `rule.mjs`). A rule that only repeated another was folded into it, and its old ID resolves with `rule.mjs` (e.g. `W1-12 → F-09`). What remains here are the few trade-offs that need judgement on the screen in front of you. Check them before shipping a restyle batch or a fix that touches the properties named.

| IDs | Tension | Resolution |
|---|---|---|
| F-06 vs A-09 / A-12 / A-05 / F-04 | Raising body text to 16px (F-06) can erase the size or colour step between a title and its subtitle, a name and its meta line (A-09), or any two text styles that differed only by that value. | Keep the playbook minimum for body text, then restore the hierarchy with weight, colour or a larger step on the heading instead of shrinking the body again (F-04, A-05). After changing a size or colour token, re-check every pair that differed only by it. |
| One-weight brand font vs E-33 | A brand that uses a single weight cannot follow "heavier headings, lighter body". | Record it under **Accepted by design** (excluded from scoring) but don't claim hierarchy by weight; hierarchy then comes from size, colour and spacing (F-04, A-05). |
| Sticky top header on mobile vs H-09 | H-09 says the top of the screen is hard to reach by thumb; a tall sticky top header also eats viewport height and holds controls in that zone. | Keep the sticky header compact (or hide it on scroll down, show it on scroll up) and keep primary actions in the thumb zone (bottom bar or bottom-anchored CTA, H-09) *(general practice for the compact/hide part)*. Give in-page anchors a `scroll-margin-top` of at least the header height. |
| B-19 / B-20 vs A-08 / C-02 | B-19 and B-20 make a large image dominant; A-08 shrinks images that steal the spotlight from name and price, and C-02 lets no element overpower the rest. | Imagery dominates where it drives the decision and the user is browsing (food, travel, fashion, real estate: B-19, B-20). In task rows (cart, order summary, selected items) text carries the row and the thumbnail stays small (A-08). Either way the heading, details and CTA stay easy to see (C-02). |
| W3-29 vs W3-27 | Depth from background tones and a hairline with no shadows (W3-29) vs elevation from three layered shadows (W3-27). | Pick one depth model per product and apply it everywhere; don't flag missing shadows in a deliberate flat-tone system, and judge either model by the playbook's depth rules (D-02, D-05). |
| C-12 vs W5-13 | C-12 trims copy so sibling cards have equal line counts; W5-13 tests layouts with real, long and missing content. | Trim copy only where the team writes it (feature, pricing, marketing cards: C-12). For user or CMS content, equalise heights and pin CTAs (C-13) and stress-test with long, empty and missing data (W5-13); never clamp real content to demo length without the full text on demand. |
